Лабораторная работа №3. Асинхронный JavaScript и REST API

Описание
«Доска публикаций»: загрузка 5 публикаций с JSONPlaceholder (GET),
создание новой публикации (POST) с валидацией формы, индикацией
загрузки и обработкой ошибок.

Файлы
- index.html — разметка интерфейса
- style.css — оформление
- app.js — логика fetch/async-await, DOM, валидация

Запуск
1. Распакуйте архив.
2. Откройте index.html в браузере (двойной клик).
   Либо запустите локальный сервер:
   `python -m http.server 8000` и откройте http://localhost:8000

Результаты проверки
- «Загрузить публикации» → отображаются 5 публикаций (заголовок + текст).
- Пустые поля / пробелы → ошибка валидации, запрос не отправляется.
- Корректные данные → ответ 201, вывод ID и заголовка, карточка добавлена.
- Подмена URL на /postz → сообщение об ошибке HTTP 404, кнопка активна.
